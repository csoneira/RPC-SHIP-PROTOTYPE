# About operating without the aluminum cover and the HV induced noise

TOMAR doesn't spike in counts with no metalic cover, so for this detector is not totally true that there is a extreme need for the screws to be very very tight.

The instability comes from the HV source, as we could see because we elevate it to worsen the grounding and suddenly a lot of noise enters the detector.

Also we know that the silver wire used in the HV surface is generating a lot of crosstalk and noises, not here specifically, but in all the RPCs with this design.
